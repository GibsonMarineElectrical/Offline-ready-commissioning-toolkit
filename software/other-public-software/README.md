# Offline installers

This folder is reserved for third-party installer executables used alongside the commissioning toolkit.

These binaries are not committed to this repository. If they are required, provide them via an internal distribution channel or as separate GitHub Release assets.

Before sharing this repository outside your organisation, confirm that redistribution is permitted for each item.

## Included
- `converter/CONVERT.EXE`
- `ecdis-simulator/EcdisSim.exe`
- `terminal/terminal-2014.exe`
