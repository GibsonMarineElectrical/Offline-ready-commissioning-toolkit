# Documentation

This folder contains short field notes used during commissioning. Each page aims to be fast to scan on site.

## Contents
- `networking/protocols/` – protocol quick references plus test examples
- `safety/` – safety cheat sheets
- `commissioning/` – commissioning notes
- `electrical/pinouts/` – folder structure reserved for pinouts

## Scope
These notes are not a substitute for OEM documentation or vessel procedures. Use them as a prompt, not as an authority.
