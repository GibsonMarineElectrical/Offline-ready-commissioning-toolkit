# Troubleshooting

## The page does not load
- Confirm the tool is running.
- Confirm the port is correct.
- Try `http://127.0.0.1:<port>` from the same machine.
- Check Windows Firewall prompts.

## Port already in use
- Close the other program using the port.
- Start the tool with `--port <n>`.

## SmartScreen or antivirus blocks the EXE
- Use the official release ZIP only.
- Extract to a local folder.
- Run the EXE from disk, not from inside the ZIP.

## The tool saves nothing
- Move the toolkit to a writable folder.
- Avoid protected folders such as `C:\Program Files\...`.
